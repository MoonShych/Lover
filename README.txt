เว็บไซต์วันครบรอบ — คู่มือใช้งาน
================================

วิธีเปิดใช้งาน
--------------
เปิดไฟล์ index.html ด้วยเบราว์เซอร์ได้ทันที (ดับเบิลคลิก หรือลากเข้าเบราว์เซอร์)
แนะนำให้ทดสอบผ่านมือถือจริงเพื่อดูอนิเมชันแบบ Full Screen แนวตั้ง

โครงสร้างไฟล์
--------------
index.html                 โครงหน้าเว็บทั้ง 7 หน้า
style.css                  ดีไซน์ทั้งหมด (สี ฟอนต์ อนิเมชัน responsive)
script.js                  ลอจิกทั้งหมด + CONFIG สำหรับแก้ไขเนื้อหา
assets/images/              รูปภาพ (ดู README ในโฟลเดอร์)
assets/music/                เพลงพื้นหลัง (ดู README ในโฟลเดอร์)
assets/sounds/                เสียงเอฟเฟกต์ (ดู README ในโฟลเดอร์)

แก้ไขอะไรได้บ้าง (ทำที่ script.js หัวข้อ CONFIG)
--------------------------------------------------
- password            รหัสผ่าน (ค่าเริ่มต้น 011025)
- anniversaryDate     วันครบรอบจริง สำหรับตัวนับเวลาในหน้า 3
- partnerName         ชื่อคนรัก
- photos              รายการรูปภาพ + คำบรรยายใต้ภาพ
- letterText          ข้อความในจดหมายรัก (พิมพ์ทีละตัวอัตโนมัติ)
- sounds / musicVolume ชื่อไฟล์เสียงและระดับเสียงเพลง

ข้อความอื่น ๆ (เช่น "สำหรับอ้วนคนเดียว 🤍", "รักอ้วนที่สุด")
สามารถแก้ไขได้โดยตรงใน index.html — ค้นหาข้อความที่ต้องการแล้วแก้ได้เลย

หมายเหตุเรื่องลิขสิทธิ์
-----------------------
ไฟล์รูปภาพ/เพลง/เสียง ไม่ได้แนบมาด้วย เนื่องจากเป็นเนื้อหาส่วนตัวของคุณ
กรุณาใส่ไฟล์ของคุณเองตามคำแนะนำในแต่ละโฟลเดอร์ assets/
